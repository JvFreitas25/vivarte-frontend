# 🎨 Vivarte Frontend

Frontend da aplicação **Vivarte**, um e-commerce de artesanato desenvolvido para estudos, consumindo uma API REST criada com **Spring Boot**.

## 🚀 Tecnologias

- React
- Vite
- JavaScript
- CSS
- Axios
- React Router DOM

## ✨ Funcionalidades

- Cadastro e login de usuários
- Listagem de produtos
- Visualização dos detalhes dos produtos
- Carrinho de compras
- Integração com a API Spring Boot
- Interface responsiva

## 📁 Estrutura do projeto

```
src/
 ├── components/
 ├── pages/
 ├── services/
 ├── assets/
 └── App.jsx
```

## ⚙️ Como executar

Clone o repositório:

```bash
git clone https://github.com/SEU_USUARIO/vivarte-frontend.git
```

Entre na pasta do projeto:

```bash
cd vivarte-frontend
```

Instale as dependências:

```bash
npm install
```

Execute a aplicação:

```bash
npm run dev
```

O projeto estará disponível em:

```
http://localhost:5173
```
